# ユーザー向け操作マニュアル敵対的レビュー

レビュー日: 2026-08-22
対象: `apps/web/src/user-manual-page.tsx`、`apps/web/src/main.tsx`、`apps/web/src/auth-context.tsx`、`e2e/user-manual.spec.ts`

## 判定

Critical 0件、High 0件。サイト内ユーザー向け操作マニュアルを合格とします。

## 確認項目

- `/manual` は認証前にも表示でき、チーム・部員データや認証情報をページへ埋め込んでいない。
- ログイン画面と認証後の部員管理画面からマニュアルへ移動できる。
- 部員一覧、部員登録、年度繰り上げの説明が、現在の権限・入力条件・状態遷移と一致している。
- Phase 2以降の未実装機能を、利用できる機能として誤案内していない。
- staging / production の環境確認と、環境未設定時に重要操作を止める注意を記録している。
- 登録通信が不確実な場合の再登録禁止、年度繰り上げ前の対象件数確認を説明している。
- 現在ログアウト操作がないため、共有端末を避ける注意を明記している。
- マニュアルの表・目次が狭い画面でも読めるスタイルになっている。

## 検証

- Node.js 24で`pnpm test`、`pnpm build`、`pnpm lint`が成功。
- Webサーバーだけを起動したマニュアル専用Playwright E2E 2件が成功。
- DBを必要とする既存の`pnpm test:e2e:local`は、`DATABASE_URL`未設定のため起動前に失敗した。マニュアル専用E2EではAPI・DBを起動せず、公開ページとログイン画面の導線を検証した。
